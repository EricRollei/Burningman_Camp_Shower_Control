Camp Shower — M5Stack Tough screen mockups

Four looks for the same five screens. Everything is drawn at the real 320×240 and shown at 1.5× so you can judge legibility at arm's length. No animations anywhere — every screen is a single static redraw. Touch is gone: the only inputs are the wristband and the one button.

Flow: Idle → tap wristband → Logged in (press button to start) → Showering (press button when done) → Summary (10 s) → Idle. Tapping a different wristband during someone's shower ends theirs and logs the new person in.

Legibility rules baked into every theme

  • One hero element per screen (name, gallons, or the instruction) at ≥ 60 px; everything else is secondary.
  • The button instruction is always the bottom band, always full width, always the same place — so people learn where to look.
  • Green = water on / go, amber = running low, red = stop / denied. Colors never carry meaning alone; the words change too.
  • Gallons show 2 decimals while showering (people like watching it tick), 1 decimal on the summary.
  • No allowance bar or “gal left” nagging — people pay for water and self-limit. Screens show what you've used: this shower, and your running total.

What the Tough can actually draw

  • Built-in M5GFX fonts: FreeSans/FreeSerif/FreeMono Bold (9–24 pt), Orbitron Light 24/32, DejaVu up to 72 px, 7-segment Font7, and big digits Font8 (75 px). The Neon and Blackout looks map straight onto Orbitron / DejaVu / Font8.
  • Rye / Alfa Slab (circus) and Righteous (motel) aren't built in, but any TTF can be converted to a .vlw bitmap font and loaded from the SD card. Headline sizes only — a couple of sizes per font is cheap.
  • Marquee bulbs, stripes, tickets, the sun, the grid floor — all plain rect/circle/line primitives, drawn once per screen. No flicker because they're not redrawn on flow updates (only the number and bar are).
