# Burning Man Shower Controller Project

## Project Goals

Build two independent solar-powered shower stations for Burning Man
that:

-   Authenticate users via RFID/NFC tags.
-   Measure and log water usage per person.
-   Enable the pump only for authorized users.
-   Store logs on an SD card.
-   Control decorative and utility lighting.
-   Provide USB-C charging only during an active shower session.
-   Operate primarily from solar with generator-assisted charging.
-   Support quick battery swaps using a single Anderson connector.
-   Survive the harsh playa environment.

The two showers are completely independent. Their CSV logs can be merged
after the event.

# Plumbing

``` text
500 gal tank
    ↓
Filter
    ↓
SEAFLO 42 Pump (12V, 3 GPM, 55 PSI)
    ↓
Accumulator
    ↓
 ├── Cold bypass
 └── Water heater
        ↓
Thermostatic mixing valve
        ↓
Flow sensor
        ↓
Shower valve
        ↓
Shower head
```

The flow sensor is installed **after** the mixing valve so it measures
the actual delivered water.

# Electrical System

## Battery

-   12.8V 40Ah LiFePO₄ battery (one per shower)
-   One Anderson SB50 quick disconnect for the entire shower system
-   Battery pigtail only contains:
    -   Positive
    -   Negative
    -   Anderson connector

## Charging

### Solar

50W panel → Solar charge controller → Battery

### Generator

110V generator → 10A LiFePO₄ charger → Battery

Both chargers connect to the **battery-side node** (ahead of the main
breaker).

Battery removal sequence:

1.  Turn off AC charger.
2.  Disconnect solar panel (or open solar disconnect).
3.  Turn OFF 30A breaker.
4.  Unplug Anderson connector.

Reconnect in reverse order.

------------------------------------------------------------------------

# Main Protection

Battery → 30A manual-reset breaker → Marine fuse block with integrated
negative bus

The breaker functions as:

-   Main disconnect
-   Main circuit protection

------------------------------------------------------------------------

# Fuse Block

Each positive branch is individually fused.

Current plan:

  Fuse    Circuit
  ------- --------------------
  15A     Pump
  5A      USB-C converter
  LED     LED strip
  3--5A   M5Stack controller
  10A     Utility lights
  Spare   Future expansion

All negative returns terminate on the fuse block's integrated negative
bus.

------------------------------------------------------------------------

# Pump Control

The SEAFLO pump is switched by an automotive relay.

M5Stack 4Relay → Automotive relay coil → Automotive relay contacts →
Pump

------------------------------------------------------------------------

# USB-C Charging

12V → Relay → 12V→USB-C buck converter → USB-C outlet

Enabled only during an authorized shower session.

------------------------------------------------------------------------

# LED Lighting

-   Approximately 24 ft around shower perimeter.
-   Planned 12V addressable strip.
-   Power directly from fused 12V supply.
-   Data from M5Stack GPIO.
-   Main power switched by relay.

------------------------------------------------------------------------

# Controller

M5Stack Tough

-   Powered directly from 12V through RS485 connector.
-   USB-C reserved for programming.

------------------------------------------------------------------------

# User Workflow

1.  Idle
2.  Scan tag
3.  Display welcome
4.  Enable shower
5.  User selects LED color/effect
6.  Pump enabled
7.  Flow measured
8.  Session logged
9.  Return to idle

# Water Measurement

Flow sensor pulse output → GPIO interrupt → Pulse count → Calibration →
Gallons/Liters

Each shower is calibrated independently.

------------------------------------------------------------------------

# Power Budget

-   40Ah battery ≈ 512Wh
-   50W solar ≈ 200--260Wh/day
-   10A charger ≈ 5 hours for a depleted 40Ah battery
-   Largest continuous load expected to be LED lighting.
